# Akanksha Maurya - Developer Portfolio Website

🌐 **Live Website:** [https://portofoliosite-ecru.vercel.app/](https://portofoliosite-ecru.vercel.app/)

A modern, high-performance, and responsive portfolio website designed for tech recruiters and hiring managers.

## 🚀 Key Highlights & Enhancements

1. **Modern Dark & Light Theme**:
   - Sleek glassmorphism navbar (`backdrop-filter: blur(16px)`).
   - Instant Dark / Light mode toggle switch with `localStorage` memory.
   - Professional gradient accents and dark slate aesthetic.

2. **Recruiter-Ready Sections**:
   - **Hero Section**: Dynamic typing effect, "Available for Opportunities" status pulse, quick CTAs (Projects, Resume, Contact), and direct social badges.
   - **Interactive Code Card**: Highlights tech stack, OOP, and problem-solving focus.
   - **Technical Skills**: Categorized into Frontend, Backend & Database, Programming & DSA (Java), and Tools & Cloud (AWS, Render, Docker) with FontAwesome icons.
   - **Education Section**:
     - B.Tech (Computer Science & Engineering) - KCC Institute of Technology and Management, Knowledge Park 3, Greater Noida.
     - Class 12th (75%) - S.G.S.I.C. Samodhpur, Jaunpur, Uttar Pradesh (Government School).
     - Class 10th (87% Distinction) - S.G.S.I.C. Samodhpur, Jaunpur, Uttar Pradesh (Government School).
   - **Languages Known Sub-Section**: Hindi, English, Awadhi, Bhojpuri with proficiency meters.
   - **Leadership & Hackathons**: Core member at Voyager Coding Club, team leader, and successfully organized 2 Hackathons with the team.
   - **Current Location**: Knowledge Park 3, Greater Noida, Uttar Pradesh.
   - **Featured Projects**: Live preview links, tech stack pills, and GitHub links.
   - **Coding Profiles**: Direct links and focus areas for LeetCode, GitHub, and LinkedIn.
   - **Contact Section**: One-click "Copy Email" with toast feedback and interactive message form.

## 🛠️ Technologies Used

* **Frontend**: HTML5, Modern CSS3, JavaScript (ES6+), React.js, Next.js, Tailwind CSS
* **Backend & Database**: Node.js, Express.js, MongoDB, RESTful APIs
* **Programming**: Java (Data Structures & Algorithms)
* **Cloud & DevOps**: AWS, Render, Docker, Vercel, Git, GitHub
